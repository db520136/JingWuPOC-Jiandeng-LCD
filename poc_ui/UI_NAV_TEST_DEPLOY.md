# EC800M 实机验证说明

## 1. 验证入口

本验证程序不使用 `main.py`，不启动 POC、RTP、GNSS、地图、OTA/MQTT、
电池、网络、肩灯、加速度或其他业务线程。本轮只验证正式页面布局、固定
状态栏和 LVGL 原生交互；登录、定位和身份数据均为入口写入的模拟快照。

入口文件：

```text
main_ui_nav_test.py
```

在 QPYcom 中运行 `main_ui_nav_test.py`。如果平台要求从 `usr` 目录运行，则运行对应的 `/usr/main_ui_nav_test.py`。

## 4. 预期画面和操作

启动后先显示模拟登录页；选择 M/F 并输入 6 位数字（例如 `100001`），
再点击“确认”后进入四个一级页面：

```text
定位 | 肩灯 | 对讲机 | 设置
```

验证：

1. 左右滑动一级页面；
2. 点击定位图标进入“定位二级页面”；点击肩灯、对讲机、设置图标进入对应二级页面；
3. 在二级页面任意位置向右滑返回；
4. 点击二级页面按钮进入三级页面；
5. 在三级/四级页面任意位置向右滑逐级返回；
6. 在设置二级页面上下滑动，确认“升级”位于列表末尾。
7. 观察固定状态栏：它不随一级页面左右滑动、子页面右滑或设置列表上下滚动。
8. 当前状态栏、定位数据和身份数据均为模拟值；没有中文字库时文字可能无法显示，
   但不影响先验证页面交互。

重点路径验证：先在一级页面滑到最后一页（例如 C），再点击进入二级页面，
从二级页面任意位置右滑返回；返回画面必须仍是 C。A/B 页面属于根槽位中
同一个内部 `tileview` 的其他 tile，不会参与子页面转场，也不应闪现。

边界方向验证：一级第一页只响应左滑，右滑从按下开始不应有位移或回弹；
一级最后一页只响应右滑，左滑从按下开始不应有位移或回弹；中间一级页面
保持左右滑动。二级、三级、四级页面只响应右滑返回上一级，左滑不应有位移
或回弹；页面内的菜单区域仍可上下滑动。

一级页面和子页面 tile 统一保留 `lv.DIR.LEFT | lv.DIR.RIGHT`，这是为了
保证页面被拖出半页后可以在同一触摸会话中反向拖回当前页。首页右滑、尾页
左滑和子页面左滑没有相邻目标页，根/子容器又关闭了横向弹性，因此最终保持
原位；下一级子页面仍通过点击事件进入。根/子容器和普通页面对象清除滚动
标志、滚动链及弹性，设置列表 viewport 是唯一允许纵向滚动的区域。页面仍
使用 LVGL tileview 原生跟手、惯性与吸附逻辑，不加入自定义页面位移。

本入口没有 Worker 或业务线程；只有 UI 主循环负责触摸轮询、LVGL 任务处理和
页面刷新。这样可以先单独观察固定状态栏、页面布局和原生滚动的流畅性。

显示缓冲为单缓冲：`296 x 40` 行 RGB565。`disp_draw_buf_t.init()` 使用像素数
作为容量参数（`296 * 40`），底层同步 `lcd_write()` 仅在 LVGL `flush_cb` 中调用。

触摸采样周期当前为 5 ms（目标约 200 Hz）。采样和 `lv.task_handler()` 均在
主循环中同步执行，不依赖串口日志进行判断。

一级页面手势阈值：位移 `0～6 px` 保留点击；超过 `6 px` 取消点击；横向
位移达到 `40 px` 且横向占主导时切换页面；`7～39 px` 为无效触摸。

一级页面 LVGL 原生滚动参数位于项目根目录的
`ui_app.py` 文件顶部（不是 `display_port.py`，也不是旧的
`lcd_touch.py`）：

```python
ROOT_SCROLL_THROW = 25  # 松手后的惯性强度
ROOT_SCROLL_LIMIT = 10  # LVGL 开始滚动的门槛
```

若当前 QuecPython LVGL 绑定未暴露对应滚动参数接口，程序会静默保留固件默认值。

### 参数测试建议

`ROOT_SCROLL_THROW` 只影响手指释放后的惯性，不影响手指按住期间的跟手
位移。建议按下面顺序测试：

| 值 | 预期效果 | 建议 |
|---:|---|---|
| 10 | 惯性很弱，松手后很快停止，页面移动距离较短 | 可测试，适合希望切换利落的情况 |
| 25 | 惯性适中，速度和稳定性平衡 | 首选默认值 |
| 40 | 惯性明显，快速滑动后继续移动更远 | 可测试，观察是否误切页 |
| 60 | 惯性很强，可能滑动过远或边界回弹明显 | 不建议作为常用值 |
| 80 及以上 | 可能出现过冲、多页误切换或回弹时间过长 | 不建议使用 |

`ROOT_SCROLL_LIMIT` 影响 LVGL 从静止状态进入滚动状态的门槛，不是页面
切换距离；业务层确认页面切换仍使用 `PAGE_SWITCH_DISTANCE_PX = 40`。

| 值 | 预期效果 | 建议 |
|---:|---|---|
| 5 | 很灵敏，轻微抖动也容易进入滚动 | 可测试，但容易误触 |
| 10 | 灵敏度和稳定性平衡 | 首选默认值 |
| 15 | 需要更明显的移动才开始滚动 | 可测试，适合减少误触 |
| 20 | 滚动启动明显迟钝，短距离快速滑动可能无响应 | 不建议作为常用值 |
| 30 及以上 | 可能明显拖滞，快速滑动容易被漏判 | 不建议使用 |

推荐实机测试组合：

```text
组合 1：THROW=10，LIMIT=10  —— 稳定、惯性弱
组合 2：THROW=25，LIMIT=10  —— 推荐基线
组合 3：THROW=40，LIMIT=10  —— 惯性明显
组合 4：THROW=25，LIMIT=5   —— 更灵敏，观察误触
组合 5：THROW=25，LIMIT=15  —— 更稳，观察短滑响应
```

每次只修改 `ui_app.py` 中的常量，重新上传该文件即可；如果固件未暴露对应
接口，修改该常量不会改变固件内部默认行为。

## 5. 本轮重点观察

- 是否正常点亮并刷新 296x240 LCD；
- 触摸点是否和画面位置一致；
- 一级页面是否能左右吸附切换；
- 首尾页面是否不越界；
- 二级/三级页面是否能逐级返回；
- 菜单上下滑动是否正常；
- 页面切换后是否仍可点击。
- 固定状态栏是否保持不动，页面切换和列表滚动期间是否出现卡顿或错位。

## 6. 如果无法启动

请保留 QPYcom 的完整串口输出，重点记录：

- `ImportError`；
- `LCD` 初始化异常；
- `I2C` 初始化或读取异常；
- `lv.tileview`、`add_tile`、`register` 等 LVGL API 异常；
- 屏幕是否有背光但无图像；
- 触摸是否有坐标响应。

本轮若异常，优先检查显示、触摸、字体资源路径和 LVGL 绑定接口；业务线程将在
纯 UI 基线通过后再接入。
